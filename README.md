# Heart Disease Prediction Project

## Project Description

This project focuses on analyzing and predicting heart disease using a publicly available dataset. The goal is to build a machine learning model that can accurately predict the presence of heart disease based on various patient attributes such as age, sex, cholesterol levels, and other relevant factors.

The project involves the following steps:

1.  **Data Loading and Exploration:** Load the heart disease dataset and perform initial data exploration to understand its structure, identify missing values, and analyze the distribution of key features.
2.  **Data Preprocessing:** Clean and preprocess the data, including handling categorical features and scaling numerical features, to prepare it for machine learning models.
3.  **Model Selection and Training:** Select and train a suitable machine learning model, such as a Random Forest Classifier, to predict heart disease.
4.  **Model Evaluation:** Evaluate the performance of the trained model using appropriate metrics like accuracy, precision, recall, and F1-score.
5.  **Hyperparameter Tuning:** Optimize the model's performance by tuning its hyperparameters using techniques like Grid Search.
6.  **Interpretation and Conclusion:** Interpret the model's results and draw conclusions about the factors that are most influential in predicting heart disease.

This project provides a practical example of applying machine learning techniques to a real-world health problem.

## Dataset

The dataset used in this project is the "Heart Disease Dataset" from Kaggle. It contains various attributes of patients, including:
- age
- sex
- chest pain type (cp)
- resting blood pressure (trestbps)
- serum cholesterol (chol)
- fasting blood sugar (fbs)
- resting electrocardiographic results (restecg)
- maximum heart rate achieved (thalach)
- exercise induced angina (exang)
- oldpeak (ST depression induced by exercise relative to rest)
- the slope of the peak exercise ST segment (slope)
- number of major vessels (0-3) colored by fluoroscopy (ca)
- thal: 0 = normal; 1 = fixed defect; 2 = reversible defect
- target (0 = no heart disease, 1 = heart disease)

The dataset can be downloaded from [https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset).
